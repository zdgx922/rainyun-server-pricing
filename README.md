## 三个最容易多花钱的地方

### 第一，NAT 和独立公网 IP 是两回事

不少机型默认 NAT，共用公网 IP，只能开固定数量的端口映射，一般 10～15 个。拿来学 Linux、做内网穿透够用，但 NAT 机不能直接搭网站。独立 IP 海外 5 元/个/月，香港移动高防 IP 40 元/月，宿迁的独享 IP 因为带 150G 防御要 150 元/月，比服务器本身还贵。一台机器最多加 3 个独立 IP。下单前先确认你要的机型给的是哪种 IP，这一项漏看，预算能翻倍。

### 第二，同价两个版本，一个限流量一个限带宽

香港 2 区同配置有两个版本，价格接近：一个给 50M 带宽配 100GB 月流量，另一个给 10M 上传带宽但不限流量。选错的代价很直接：站点图片和视频多，100GB 一个月就见底；反过来，访问量不大却买了不限流量版，钱花在永远用不上的带宽上。

流量用不完可以结转到下个月。用超了会被限速到 5M（部分机型描述为 1M），不会直接停服，想恢复高速得另买流量包，价格按地区不同，大约 100 元/1TB 到 200 元/1TB。

### 第三，硬盘扩容单独计费

大多数套餐默认 30GB，扩容按 0.3～0.4 元/GB/月（固态）或 0.1 元/GB/月（机械）算。跑数据库、存镜像、备份站点，这块钱别漏算。100GB 固态额外空间一年就是 360～480 元，比一台入门机的年费还高。空间需求大就一开始选大硬盘方案，别等装满了再补。

## 常见问题

**国内节点一定要备案吗？**
绑域名对外提供网站服务要备案，江苏宿迁、镇江、浙江宁波、湖北十堰都算国内节点。只跑数据库、学习研究不需要独立 IP，也不用备案。香港、日本、韩国、德国、美国节点免备案。

**流量用超了会直接停机吗？**
不会。限速到 5M（部分机型 1M），网站还能访问，只是变慢。恢复高速买流量包，约 100～200 元/1TB。当月没用完的流量可以结转到下月。

**一台机器能加几个 IP？**
最多 3 个独立 IP。海外 5 元/个/月，香港移动高防 IP 40 元/月，宿迁独享 IP 150 元/月。

**能装什么系统？**
Linux 和 Windows 都能装，宝塔、1Panel 可以一键部署。macOS 只支持香港 2 区、香港 4 区和湖北十堰，其他区域不行。

**和阿里云、腾讯云差在哪？**
品牌背书和 SLA 层级不同，雨云没有首年低价、续费翻倍的定价套路，年付 7 折是长期一致的。代价是机房和线路要自己挑，客服时段也短一些。

**开 Minecraft 选游戏云还是云服务器？**
5～10 人的服选游戏云面板，有一键开服和可视化管理。动态计费模式下无人在线超过设定时长（可设 5～60 分钟）自动停止计费，只在周末开服，月开销可能不到固定计费的六成。24 小时长开、CPU 长期高于 20%，固定计费更划算。
